# SQL Server DBA Scripts

One script per area. Open in SSMS and run statements individually.
Scripts are read-only unless a block is marked [CHANGES DATA] or [CHANGES CONFIG] (those blocks are commented out).
Scripts that query a single database (indexes, statistics, Query Store, security, maintenance) must be run in the target database (USE [YourDB]).
